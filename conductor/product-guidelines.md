# Product Guidelines — EPMS

## Design Principles
- **Enterprise Polish**: Modern dark glassmorphism, curated color scales, zero generic AI template aesthetics.
- **Mobile-First Utility**: Built for fast, one-handed touch operation on mobile viewports (375px+).
- **No Emoji Glyphs in UI**: Use standard Lucide SVG icons instead of raw emojis for navigation and actions.
- **Zero Unhandled Crashes**: Graceful error boundaries, offline support for gate scanning, designed empty states.

## Accessibility Guidelines
- WCAG 2.2 AA compliance.
- Inputs must enforce 16px font-size minimum to prevent mobile Safari auto-zoom.
- High-contrast visual cues alongside audio feedback on gate scan result screens.
